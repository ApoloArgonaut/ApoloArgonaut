### Proyectos

**[wrc-01-speed-since-1973](https://github.com/ApoloArgonaut/wrc-01-speed-since-1973)** — ¿Cuánto más rápido es un rally que hace 50 años? 633 rallys del WRC (1973–2026) extraídos de un archivo público. El resultado: **+19.9 km/h**, pero sólo **+16.5** al controlar por el recorte del recorrido, que es el confundidor que casi nadie separa.

Python sin dependencias de runtime, CLI con subcomandos, SQLite. **96 tests, 92% de cobertura.**

**[covid-survey-analysis](https://github.com/ApoloArgonaut/covid-survey-analysis)** — Análisis de una encuesta COVID-19 (2021): pipeline reproducible `raw → interim → processed`, EDA en Jupyter y dashboard en Streamlit. Estructura bilingüe ES/EN.
