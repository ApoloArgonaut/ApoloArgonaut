### Proyectos

**[wrc-01-speed-since-1973](https://github.com/ApoloArgonaut/wrc-01-speed-since-1973)**. ¿Cuánto más rápido es un rally que hace 50 años? 633 rallys del WRC entre 1973 y 2026, sacados de un archivo público. La diferencia es de 19.9 km/h, pero baja a 16.5 al controlar por el recorte del recorrido, que es el confundidor que casi nadie separa.

**[job-market-analyzer](https://github.com/ApoloArgonaut/job-market-analyzer)**. Descarga ofertas de cinco bolsas de empleo públicas, las clasifica por perfil y mide qué habilidades piden de verdad, con intervalos de confianza. Python sin dependencias de runtime, CLI con subcomandos y SQLite. 96 tests y 92% de cobertura.

**[Pactio](https://github.com/ApoloArgonaut/Pactio)**. Plataforma de acuerdos para freelancers. Caso de estudio de UX/UI/CX: investigación, arquitectura de información, prototipo funcional en React y TypeScript, y pruebas de usabilidad con 8 participantes. SUS 87.8 (percentil 96), 95.8% de éxito en tareas, 3m 42s para crear un acuerdo.

**[covid-survey-analysis](https://github.com/ApoloArgonaut/covid-survey-analysis)**. Análisis de una encuesta de COVID-19 de 2021: pipeline reproducible de raw a processed, EDA en Jupyter y dashboard en Streamlit.
